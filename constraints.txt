# constraints.txt — exact versions for the Docker image and CI.
#
# requirements.txt says what the app needs (loose ">=" ranges). This file says
# exactly which versions to install, so a rebuild next month resolves to the
# same packages as the build that was tested. pip applies it with "-c":
#
#     pip install -r requirements.txt -c constraints.txt
#
# A constraint only pins a version; it never installs anything by itself.
#
# torch/torchvision are written without their "+cpu" suffix on purpose.
# Under PEP 440, "torch==2.14.0" matches "2.14.0+cpu", so the same file works
# for the CPU-only index the Dockerfile and CI install from.
#
# Resolved for Linux x86_64, Python 3.12 (python:3.12.14-slim-trixie).
# To upgrade, regenerate the pins from a clean resolve (bash, repo root):
#
#     docker run --rm -v "$PWD:/work:ro" python:3.12.14-slim-trixie sh -c '
#       pip install -q torch torchvision --index-url https://download.pytorch.org/whl/cpu &&
#       pip install -q -r /work/requirements.txt && pip freeze' | sed 's/+cpu$//'
#
# then re-add this header and run the tests before committing.
